# Author-verification

Purpose: the data-processing step of Karam Abu Mokh's M.Sc. final project on ancient Arabic author verification: Arabic text to clean tokens, then labelled chunks for every pair of texts. A public repository shown on his portfolio (karamam.com). Only this first step is public.

## Files
- `README.md`: what the whole project is, what this repository holds, how to run it and the structure.
- `.gitignore`: ignores the local virtual environment folder.
- `AGENTS.md`: this file.

## Folders
- `DataProcessor/`: the Python code (tokenizing and chunk labelling).
- `data/`: four Arabic sample texts and their tokens.
- `docs/`: two project figures that the README shows (its own `AGENTS.md` lists them).
